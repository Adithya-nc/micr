# Architecture

## Intelligence Plane
One ResolveSphere Orchestrator routes SK-01 through SK-04 and SK-07. Qwen receives redacted minimum necessary context, produces strict JSON, and requests only approved read tools.

## Control Plane
Pydantic models validate contracts. Deterministic functions evaluate evidence authority and freshness, sufficiency, contradictions, policy, risk, authorization, contract hashes, approvals, idempotency, and transitions.

## Execution Plane
Only SK-06 invokes approved workflows or sequential deterministic fallback. Refund execution is SIMULATED against synthetic records. Completion is distinct from authoritative predicate verification.

## Resolution Rule
A case resolves only after a VERIFIED Verification Receipt. A failed verification reopens then reinvestigates within limits; two failures escalate. A later mismatch against a resolved case creates an append-only linked reopened successor.
